splay

Render any data. Register one viewer for each type. dispatch finds the type of each value, calls its viewer, and the viewer calls ctx.render for the values inside. The output is yours: elements, strings or component data.

How dispatch works

The core is about 200 lines of TypeScript with no dependencies. Each call of dispatch does these four steps.

  1. 1

    Find the type

    inferType(data) gives "null", "undefined", "function" or the typeof of a primitive. For an object, the value of its TYPE_SYMBOL comes first, then "array", "date" and "object".

  2. 2

    Find the viewer

    registry.get(type) gives the viewer of that type. A registry is a map from a type to a viewer.

  3. 3

    No viewer? Use the fallback

    With no viewer, dispatch gives fallback(type, data), or undefined when the config has no fallback. Turn off a viewer above to see it.

  4. 4

    Call the viewer

    The viewer gets ctx: data, size, path, depth and render. ctx.render(child, size, path) starts step 1 again for each nested value.
